# 🎨 Pixel Font – Design & Download Styled Text ✨

A **responsive React app** to customize text with colors, fonts, background images, and more — then download your creation as an image!

🔗 [Live Demo](https://pixel-font.netlify.app)

---

## ✨ Features

- 🎨 Change **text color** using buttons or color picker
- 🖼️ Apply **background color** or **background image**
- 🖋️ Choose from various **font styles** and **font sizes**
- 📐 Align text (left, center, right, justify)
- 📥 Download styled text as a **.png image**
- 📱 Fully **responsive** layout with clean UI

---

## 💡 Logic Overview

- Uses `useRef()` to apply styles dynamically to editable text
- `html2canvas` captures the styled text block as a downloadable image
- All actions (color, font, size, alignment) update in real-time

---

## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [JavaScript (ES6)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [html2canvas](https://html2canvas.hertzen.com/) – For image capture
- [Netlify](https://www.netlify.com/) – For deployment

## 🚧 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/yeshu450/pixel-font.git

# Navigate into the project folder
cd pixel-font

# Install dependencies
npm install

# Start the dev server
npm run dev
```
